LIVE PAIRING CODE
----------

Each code lasts up to 30 minutes. Keep the camera page open while your Roblox character is moving.

Use it in Mr H Reanimate

  1. Run the latest Mr H Reanimate loader in Roblox.
  2. Enable reanimation, then select Movesets → Camera Motion.
  3. Click Start Camera here and allow webcam access.
  4. Enter this code in the moveset settings and click Connect Webcam.
  5. Stand far enough back for your whole body to appear on camera.

Optional Python mode: run the provided r6_tracker.py on a PC (pip install mediapipe opencv-python numpy), select Local Python v2 in Camera Motion settings, and set its tracker URL to http://127.0.0.1:8080/pose if Roblox runs on the same PC, or your PC's private Wi-Fi address if Roblox runs on another device. For LAN use start Python with --host 0.0.0.0, allow access only from trusted devices, and keep port 8080 private.

Tracking uses R6 shoulder, hip, neck and torso rotation matrices with an upright calibration. It is not full-body physics or guaranteed server-side replication. No Python installation is needed in browser mode. Camera frames never leave this browser; only estimated joint angles pass through a temporary session. On mobile, use a second device for the camera so this page remains active.
