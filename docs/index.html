The audio that goes with the animation. Include the correct soundtrack file.

03
⌘

Module .lua

The Lua source connecting the animation, playback behavior, and music. It must match the engine's module API.

Important: This uploader packages files—it does not automatically generate a working Lua module or install the pack in Roblox. Check the Lua code before running it. Compatibility requires the module to reference the correct assets.
